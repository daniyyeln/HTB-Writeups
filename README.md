## 🔐 Public vs Private content

**Public**:
- Cleaned writeups suitable for public posting (Markdown + screenshots).
- High-level PoC and remediation advice.
- No clear-text passwords, private keys or destructive payloads.

**Private** (kept offline / in a private repo):
- Full technical details (payloads, raw outputs, shell transcripts).
- Passwords, keys, DB dumps and any artifacts that should not be public.
- Use a private repository or local encrypted storage for these artifacts.
